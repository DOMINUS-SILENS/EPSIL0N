  <<namename>Task 2: Implement ProjectionEngine</name>
  <<filesfiles>packages/kernel/src/Infrastructure/Projection/ProjectionEngine.php</files>
  <<actionaction>
    Implement `ProjectionEngine` with the following logic:
    - Constructor accepts `IEventStore` and a collection of `IEventProjector`.
    - Method `run(int $batchSize = 100)`:
      1. Determine the current minimum offset across all projectors from `projection_offsets`.
      2. Fetch events from `EventStore::getEventsFromPosition($minOffset, $batchSize)`.
      3. For each event:
         a. Dispatch to all registered `IEventProjector` instances.
         b. Update the `projection_offsets` table for each projector that successfully processed the event.
      4. Repeat until no more events are found.
  </action>
  <<verifyverify>
