  <name>Task 2: Create SyncVersion vector clock value object</name>
  <files>packages/kernel/src/Domain/Sync/SyncVersion.php</files>
  <action>
    Create SyncVersion value object representing a vector clock.

    Vector clock structure: array{deviceId => int} (e.g., ['device-1' => 5, 'device-2' => 3])

    Properties:
    - vector: array<string, int> - Map of device ID to version

    Factory methods:
    - initial(): self - Create empty vector clock (no events)
    - fromArray(array $vector): self - Create from array
    - fromJsonString(string $json): self - Create from JSON (for DB)

    Core methods:
    - increment(DeviceId $device): self - Increment version for a device (returns NEW instance)
    - merge(self $other): self - Merge two vector clocks (max of each key)
    - getVersion(DeviceId $device): int - Get version for specific device

    Comparison methods:
    - happensBefore(self $other): bool - True if ALL other keys >= self keys AND at least one strictly greater
    - isConcurrentWith(self $other): bool - True if neither happensBefore the other
    - isSameAs(self $other): bool - True if vectors are identical

    Serialization:
    - toArray(): array
    - toJsonString(): string
    - toDbArray(): array{device_id: string, version: int}[] - For JSONB storage

    Vector clock laws (MUST hold):
    1. Deterministic merge: merge(A, B) === merge(B, A)
    2. Transitive: if A happensBefore B and B happensBefore C, then A happensBefore C
    3. Merge preserves causality: merged version >= individual versions
  </action>
